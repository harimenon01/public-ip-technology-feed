# Public IP and technology feed

An independent, generic public RSS/Atom headline collector. It outputs titles, original URLs, source and publication date; it does not collect article bodies, personal profiles, private search terms, or personalized rankings. This project is not affiliated with any source. Generic source-level `topics` and `domains` are broad labels, not article classification; `summary` is empty. Never put private information or credentials in this public repository, its source list, workflow, logs, or output.

Run `python3 -m unittest discover -s tests` and `python3 collector.py`. Python standard library only. The daily workflow runs at 06:17 UTC: 06:17 London time in winter, 07:17 in summer. It can be run manually. Scheduled GitHub runs can be delayed or dropped, and schedules in inactive public repositories may be disabled. https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule

The feed is bounded to 400 items from the past 30 days, and items without a parseable publication date are excluded. Sources typically expose a finite current feed, so an initial collection is not a comprehensive 30-day archive. Each source has an explicit HTTPS host allowlist, which also constrains redirects; response bytes, time and retry count are bounded. RSS 2, Atom and RSS 1 feed entries are supported. XML document type and entity declarations are rejected. Canonical URLs strip common tracking parameters and fragments. Source failures retain earlier eligible items and are exposed in the source status. `generated_at` is the actual run time; `last_successful_at` stays unchanged if all sources fail. Items may be stale even when another source succeeds: check source statuses and original dates. The overall status is complete, partial or failed. A failed run saves status and reports failure to Actions.

## Source register and limitations

The source list uses five UK government departmental/agency news searches plus UK Research and Innovation, and three broad arXiv subject feeds; it is not exhaustive and is UK/academic-heavy. Feed endpoint reachability and permissions need verification in the execution environment. arXiv is preprint research, not general news, and its entries are not necessarily peer reviewed. Publisher availability, format and content can change. Feeds can contain few results or no recent items; a successful retrieval does not guarantee comprehensive coverage. Individual source terms, rate limits, and rights to reproduce titles or distribute metadata must be checked before publication. Code's MIT licence does not license source content. GOV.UK reuse is subject to applicable Crown copyright conditions: https://www.gov.uk/help/terms-conditions . arXiv terms: https://info.arxiv.org/help/license/index.html .

## Hosting

Create a public repository and place these files at its root, run tests, enable Actions, and trigger a manual run before relying on the schedule. Only `feed.json` is committed automatically, with narrowly scoped `contents: write`. Public repository and output are world-readable. A Site reading the output needs separate implementation and verification, with privacy-preserving matching performed within the private Site. No authorization to access a private Site or database is provided by this collector. GitHub Actions limits and pricing: https://docs.github.com/en/actions/concepts/billing-and-usage .
